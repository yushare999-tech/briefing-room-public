기존에 등록된 안건이나 부원들의 소중한 투표·댓글 데이터를 전혀 삭제하지 않고, 자율학습실 좌석 예약제 및 인스타그램 숏폼 릴스 운영안 2개(각 10개 실전 댓글 및 선택지 포함)를 새롭게 추가 등록합니다.

전체 안건 및 댓글 풀 백업 다운로드

JSON 파일 저장

모든 안건과 각 안건의 하위 실전 댓글, 투표수 집계, Gemini AI 요약 히스토리를 1개의 순수 JSON 파일로 패키징하여 즉시 내 PC나 스마트폰으로 안전하게 내려받습니다. (약 30~80KB의 초경량 파일)

백업 파일 불러오기 및 데이터 복원 (Restore)

2가지 복원 모드

이전에 백업해 둔 .json 파일을 불러옵니다. 파일을 선택하면 기존 데이터를 유지하고 추가(Append)할지, 전체 덮어쓰기(Overwrite)할지 안전하게 선택할 수 있습니다.
